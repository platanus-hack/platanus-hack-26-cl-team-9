# For reviewers: claims and where to verify them

For a technical reviewer, human or automated. Each claim the project makes is paired with the file, test or command that checks it, so you can confirm or reject it without reading the whole tree. Facts only: where a claim has a limit, the limit is in the same row or in "Limitations" below. For the map of the code see [`code-map.md`](code-map.md); for every doc see [`README.md`](README.md); for a machine-readable index of files, symbols, routes and tests see [`index/README.md`](index/README.md).

Source paths such as `domain/cascade/engine.py` are under `backend/src/cascadasen/`, test paths such as `unit/test_cascade.py` under `backend/tests/`, and paths that start with `docs/`, `web/`, `data/`, `scripts/` or `.github/` are from the repository root. `path:line` points at the definition and was read from the code at the commit that last edited this file.

## 3. Limitations

Each one is stated elsewhere in the docs; this list gathers them.

- **Reduced network.** 188 buses and 273 lines (a reduction of PyPSA-CL), not the full SEN. A click cuts a whole reduced line: where several circuits run in parallel, that is the whole corridor (`docs/engine.md`, "Assumptions").
- **Two engines.** Validation cases V1-V10 run on the 13-area engine (`POST /api/v1/simulate`). The map, sessions and the theatre use the 188-bus engine, which has V1 and pinned results only (`docs/adr/0001-two-engines.md`, `README.md`).
- **No voltage.** The 25F voltage collapse is a rule on one corridor with published limits (`docs/adr/0003-dc-power-flow.md`). Reactances are PyPSA-CL values, not measured line data (`docs/engine.md`, "25F check").
- **Not modelled:** secondary control (AGC) and operator load shedding within the 20 s horizon, generator ride-through trips, battery energy limits, the extreme-contingency EDAC (`docs/engine.md`, "Not done" and item 5). The results at "Nov 2026 20:00" read as "without operator action within about 20 s".
- **Not predictions.** Cyber scenarios are consequence estimates; no public measurement exists to test them (`docs/idea.md` section 5). Cost is a regulatory valuation (VoLL 8.79 US$/kWh), not a measured loss (`docs/engine.md`, "Cost").
- **No user validated.** The user and decision in `docs/idea.md` section 3.1 are a hypothesis.
- **Tests.** The four Chilean source adapters have no unit test, and neither does `useSession`, `useAssistant` nor `CascadeApp` (867 lines). The web bundle is one chunk of about 3.1 MB. `npm ci` prints an `npm audit` notice that has not been triaged, and `npm run build` warns about a chunk over 500 kB.
- **Access.** No authentication anywhere: the session id in the path is the credential (`docs/adr/0004-sessions-on-s3-by-url-capability.md`), and CORS allows any origin (`api/app.py:74`).
- **UI not built:** the tabs "Qué lo habría evitado" and "Validación" (disabled or hidden, `docs/mapa3.md` section 4), and the defence-mode and cause selectors described in `docs/idea.md` section 3.2.
- **Shared sessions are hidden in the web** since #101 (`docs/mapa3.md` section 11). The API, the MCP server and the assistant still use them.
- **Data.** The IDE Energía licence was not checked (`docs/datasets.md` section 2.3). The raw downloads are not committed; `data/processed/` is.
- **Not run by this documentation step:** a real browser session. The web checks are `tsc`, `vitest` (including three jsdom component tests) and `build`.
